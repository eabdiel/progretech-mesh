# Mesh v1 Product Acceptance

A v1 release should preserve all of these guarantees:

1. Plug-and-monitor attachment is non-interfering.
2. Existing agent work/channels continue when Mesh connects or disconnects.
3. Telegram and Mesh conversations stay independent.
4. Cross-channel activity can be observed and filtered.
5. Normal users need only Mesh access and a direct chat to the agent.
6. Normal users do not need workstation access.
7. No arbitrary remote shell exists.
8. Bidirectional files remain bounded and ephemeral.
9. Durable cloud operational history remains off.
10. Production CodeSeal wording requires real cryptographic verification.
11. Notifications are user-controlled per agent.
12. Guided Training is available in the product.
13. Desktop, phone, and foldable layouts remain usable.
14. Cloud production deployment stays gated until separately accepted.
