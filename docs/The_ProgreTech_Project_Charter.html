Authoritative direction

North star: autonomous delivery that becomes less dependent on outside AI over time

ProgreTech is building an AI-operated software, PWA and automation factory. Edwin supplies intent, business authority, protected-environment bridging and consequential approvals. Rend, Mak and Lyra progressively turn that intent into specifications, code, tests, deployable artifacts, operating evidence, training material, content and follow-on improvements.

Primary maturity rule: external AI is a teacher, not the workforce. The goal is not merely to route a hard task to a better API. The goal is for the local intern to learn why it was blocked, retain the validated lesson, retry locally when practical, and require less repeated outside teaching over time.

Hardware, APIs, memory systems and orchestration are supporting infrastructure. They are justified only when they increase autonomous task success, reduce repeated escalation, improve safe concurrency, or remove a measured delivery bottleneck.

Learning substrate

MemPalace is the durable learning layer — not a side roadmap

PT-2026-009 already proved the agent-neutral MemPalace foundation: SQLite/FTS5, explicit recall/learn, private/shared/project/procedure scopes, provenance, duplicate protection, correction/supersession, admission controls and migration-safe backup. That work is no longer a future “Rend pilot.” It is part of the factory substrate.

The next memory work is therefore not a separate MemPalace project. It is to connect the hybrid learning ladder to the proven memory model: teacher-derived lessons, validated fixes, reusable implementation patterns and failure signatures should be admitted deliberately into the correct project/procedure/shared scope.

MemPalace stores

Decisions, rationale, reusable troubleshooting knowledge, validated procedures, project context, handoffs, learned patterns, provenance, confidence and supersession history.

It does not replace

Git for code, the task ledger for task state, artifacts for evidence, or human approval for authority. Raw chat transcripts, secrets and transient execution state do not become memory by default.

Team model

Rend keeps orchestration/SRE memory; Mak will receive implementation/engineering memory; Lyra will receive product/front-office memory. Shared memory contains curated project facts, conventions, reusable factory knowledge and attributable handoffs. Lyra and Mak inherit the same schema when they arrive rather than spawning new memory architectures.
