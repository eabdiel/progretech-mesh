# Guided Training — Release Completion Requirement

Guided Training is intentionally scheduled after the core v1 workflows stabilize.

It should be a user-facing interactive walkthrough, not a development roadmap.

## Planned walkthrough

1. Mesh orientation and sign-in
2. Connect an agent using agent-led enrollment
3. Explain plug-and-monitor
4. Explain channel isolation
5. Read the live activity stream
6. Start an independent Mesh conversation
7. Enable per-agent notifications
8. Understand identity/trust indicators
9. Review approvals and safe actions
10. Send a file to an agent
11. Download an agent-created artifact
12. PWA/mobile/foldable usage
13. Disconnect/revoke access safely

## Rules

- no phase numbers or developer terminology
- no assumption of workstation/terminal access
- responsive on desktop, phones, and foldables
- skippable and restartable
- contextual highlighting rather than a long help document
- no sensitive data copied into tutorial state
- training should reflect the final UI rather than forcing UI around the tutorial
